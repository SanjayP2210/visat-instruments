# Efficient Coding Instructions

- Inspect only files directly related to the task.
- Never scan the entire repository unless necessary.
- Reuse existing components, API fields, database columns, and utilities.
- Make minimal changes and avoid unrelated refactoring.
- Do not print full files or large logs.
- Run only relevant tests.
- Limit command output: pipe tests/builds through `tail -n 40` or `grep`, run single spec files.
- Keep explanations and final summaries concise.
- Ask before making major architectural changes.
